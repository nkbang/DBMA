## 지적 — "단순 합산 2,257(41.4%)"만 스크립트에 없다

CUE가 스크립트를 재실행해 stdout 전체를 grep했지만 `2257`이나 `41.4`는
**한 번도 출력되지 않았다.** 손으로 8개 행을 더해봐도 재현이 안 된다:

```
L0 포함 합: 852+1153+1+15+4+0+8+374 = 2407  (문서 주장 2257과 다름)
L0 제외 합: 1153+1+15+4+0+8+374    = 1555  (역시 다름)
```

즉 이 숫자는 실행도 안 됐고 손계산으로도 안 맞는다.
