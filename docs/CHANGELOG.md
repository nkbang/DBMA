# DBMA Changelog

## 목적

이 문서는 DBMA 프로젝트의 중요한 변경 사항을 날짜별로 기록한다.
구조 변경, 파이프라인 변경, 문서 변경, 기능 변경을 간단히 추적하기 위해 사용한다.

```md

- 결과:
```

### 2026-06-22

- 변경 사항: CLAUDE.md 운영 규칙 정리
- 대상 파일: `CLAUDE.md`

- 변경 사항: 문서 체계 분리

- 변경 사항: 상태와 로그 문서 추가
- 대상 파일: `docs/STATE.md`, `docs/PROCESS_LOG.md`

### 2026-06-22
