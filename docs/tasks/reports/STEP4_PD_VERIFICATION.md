# STEP4 Public Domain Verification Plan

작성일: 2026-07-31
대상: The New Hampshire Confession of Faith (1833)
목적: 원문 확보(다운로드) 승인 이전에, 확보 시 어떤 절차로 Public Domain 여부를 검증할지 계획. 이번 문서는 절차 계획만 다루며 실제 검증(원문 확보 필요)은 수행하지 않음.

## 확인 항목

### 1. Publication Date

- 확인 대상: 1833년 최초 채택/발행 연도가 신뢰 가능한 출처(역사 문헌, 침례교 교단사 기록)로 뒷받침되는지
- 방법: 확보한 원문 자체의 판본 정보(title page, 서문)와 2차 사료(침례교 역사서) 교차 확인
- 현재 상태: 1833년은 일반적으로 통용되는 연도이나, 이번 계획 문서 작성 시점에는 원문 대조 전 — 확보 후 재확인 필요

### 2. Public Domain Basis

- 확인 대상: 저작권 보호기간 만료 근거
  - 원저작물: 집단 저작(New Hampshire Baptist Convention), 1833년 발행 — 미국 기준 1928년 이전 출판물은 사실상 PD로 간주되는 일반 원칙 적용 가능
  - 한국 저작권법 기준: 사후 70년 — 집단 저작이므로 개인 저자 사망 연도 적용이 애매함, 공표 후 기산 규정 적용 여부 확인 필요
- 방법: 확보 예정 판본이 원문 그대로인지, 편집자의 현대 서문/각주가 추가된 판본인지 구분 — 후자는 편집저작권이 별도로 존재할 수 있음
- 위험: 특정 출판사가 재편집·재조판한 판본을 사용할 경우 그 판본 자체는 PD가 아닐 수 있음(원문 텍스트는 PD이나 특정 편집물은 아닐 수 있음) — 원문 그대로의 스캔/전사본을 우선 확보해야 함

### 3. Source Reliability

- 확인 대상: 확보 예정 출처가 원문을 정확히 전사했는지(오탈자, 누락 조항 없음)
- 방법: 확보 후 최소 2개 이상 독립 출처(예: 서로 다른 아카이브)와 대조하여 조항 수(18개) 및 핵심 문구 일치 확인
- 이번 계획 문서에서는 대조 대상 저장소만 사전 조사(항목 4 참고), 실제 대조는 확보 후 수행

### 4. Preferred Repository

원문 확보 시 우선 고려할 저장소 후보 (다운로드는 이번 단계에서 미실행):

| 저장소 | 특징 | 우선순위 |
|---|---|---|
| CCEL (Christian Classics Ethereal Library) | 기독교 고전 전문, 텍스트 품질 높은 편, 신앙고백서 다수 보유 | 1순위 후보 |
| Internet Archive | 스캔본 + OCR 텍스트 병행 제공, 원본 대조 가능 | 2순위 후보 (원본 이미지 대조용) |
| Project Gutenberg | 순수 텍스트 위주, 신학 문서 수록 여부 낮을 수 있음 | 3순위 후보 |

## 결론 (계획 단계)

- 검증 절차는 4단계(발행일/PD 근거/신뢰성/저장소)로 계획됨
- 실제 검증은 원문 확보 승인 및 확보 완료 후 진행 — 이번 문서는 **계획**만 제공
