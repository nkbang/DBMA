# STEP5 Manual Verification Checklist

작성일: 2026-07-31
목적: WebFetch 도구가 verbatim 텍스트를 확보하지 못하는 구조적 한계(STEP5_SOURCE_COMPARISON.md)로 인해, 실제 원문 확보는 **사람이 직접 신뢰 저장소에서 텍스트를 복사하거나 파일을 다운로드하는 방식**으로 전환되어야 함이 확인됨. 이 문서는 그 결과물을 사람 또는 후속 세션이 검증할 체크리스트.

## 검증 항목

### 1. Heading Preservation

- [ ] 문서 제목("The New Hampshire Confession of Faith" 또는 동등 표기)이 원문 그대로 보존되었는가
- [ ] 도입부(누가/언제 작성했는지 설명하는 preamble)가 있다면 본문과 구분되어 남아 있는가
- [ ] 각 조항 제목("Of the Scriptures" 등)이 원문 표기 그대로인가 (임의 번역/의역 없음)

### 2. Confession Article Numbering

- [ ] 조항이 1번부터 순서대로 빠짐없이 존재하는가 (알려진 구조 기준 18개 조항 — 정확한 개수는 확보한 원문 자체로 재확인해야 하며, 이번 세션에서 특정 숫자를 단정하지 않음)
- [ ] 번호 체계(아라비아 숫자 vs 로마 숫자 등)가 원문과 일치하는가
- [ ] 조항 사이 경계가 명확한가 (한 조항의 끝과 다음 조항의 시작이 뒤섞이지 않았는가)

### 3. Missing Text Detection

- [ ] 문서 끝(마지막 조항 이후)에 갑자기 텍스트가 끊기지 않았는가 — 도구 기반 요약/발췌 과정에서 후반부가 누락되는 경우가 흔함(이번 세션 WebFetch 결과가 실제로 이 패턴을 보임)
- [ ] 각 조항 내부에 성경 구절 인용이 포함된 원문이라면, 인용이 임의로 생략되지 않았는가
- [ ] 문서 전체 단어 수/문단 수가 알려진 원문 분량(약 2,000~3,000단어 수준으로 알려짐)과 현저히 다르지 않은가 — 지나치게 짧다면 요약본일 가능성 높음

### 4. Encoding

- [ ] 파일이 UTF-8로 저장되었는가 (`file --mime-encoding` 등으로 확인 가능)
- [ ] 특수문자(예: 옛 영어 철자, 이탤릭체 표기가 텍스트로 변환되며 생긴 기호)가 깨지지 않았는가
- [ ] 줄바꿈 문자가 일관적인가(LF 권장, 원본 출처에 따라 CRLF가 섞여 있을 수 있음 — 통일 필요)

## 이번 세션에서 확인된 실패 사례 (참고용)

STEP5-B에서 `WebFetch`로 3개 URL(Wikisource 일반 페이지, Wikisource raw export, Reformed Reader)을 시도한 결과:
- 3건 모두 **요약본**만 반환 (18개 조항을 각 1문장으로 압축) — Missing Text Detection 기준으로는 명백한 FAIL 사례
- Reformed Reader 시도는 도구 스스로 "완전한 verbatim 재현에 한계가 있다"고 응답 — 이는 신뢰할 수 있는 실패 신호로 간주하고 그 결과를 원문으로 채택하지 않음(올바른 처리)

## 권장 확보 절차 (이번 문서의 결론)

1. 사람(HQ 또는 담당자)이 브라우저로 직접 CCEL/Wikisource/Internet Archive 중 한 곳에 접속
2. 원문 텍스트를 직접 복사하거나 파일(TXT)로 다운로드
3. 위 4개 검증 항목을 사람이 직접 대조
4. 검증 통과한 파일을 `data/nae/sources/baptist/nhc_1833.txt`로 전달
5. 이후 STEP5_SOURCE_VERIFICATION.md(문서 자체는 다음 반복에서 실제 값으로 작성) 및 registry 갱신 진행

## 이번 세션 도구의 구조적 한계 정리

- `WebFetch`: 소형 모델을 거쳐 응답을 생성하는 구조이므로 대용량 verbatim 텍스트 확보에 부적합 — 짧은 발췌/사실 확인용으로는 유효하나, 문서 전체 인제스트 목적으로는 사용 불가로 결론
- `WebSearch`: 저장소 후보 탐색에는 유효했음(이번 세션에서 5개 이상의 후보 저장소 발견) — 확보 자체가 아닌 "어디서 찾을지" 조사 단계에서만 유용
