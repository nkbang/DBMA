작성일: 2026-07-31

## 비고

- 목록은 영문 자료 위주이며, 한국어 번역본은 대부분 별도 저작권(번역자/출판사)이 존재하므로 원문(영문)과 번역본을 구분해 재검토 필요.
- 실제 수집 시 출처(예: Internet Archive, Project Gutenberg, CCEL)별 스캔본 품질과 OCR 정확도 사전 확인 필요 — 이번 단계 범위 아님.
- 본 목록은 초안이며, HQ 승인 후 우선순위 재조정 및 실제 수집 절차(별도 Task Order)로 이어질 예정.
