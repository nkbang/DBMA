## 0. 배포 버전 정의 — 무엇을 "실사용 가능"으로 볼 것인가

벤치마킹 판정(§4)대로 목표는 **상업 제품 대체재가 아니라 "근거 없는 설교를 만들지 않는
로컬 개인 서재 연구 보조기"**다. 이 정의에서 배포 버전 v1.4.0-beta는 다음을 만족한다.

| # | 조건 | 검증 방법 |
|---|---|---|
| R1 | 자료 0건이면 설교 생성이 **차단**되고 사유가 화면에 표시된다 | 자동 테스트 + 빈 코퍼스 실기 |
| R2 | 모든 설교·답변의 인용에 **책 제목·저자**가 찍힌다 (null 없음) | 자동 테스트 + 샘플 10건 육안 |
| R3 | 생성된 설교가 **저장·재열람**된다 (근거·판정 포함) | 앱 재시작 후 목록 확인 |
| R4 | 동봉 자산 전량이 퍼블릭 도메인이거나 사용 허락을 받았다 | 전수 목록 + 근거 기록 |
| R5 | 한글 성경 본문 경로가 결정·구현되어 본문 없이 설교 개요가 나가지 않는다 | 실기 |
| R6 | 목회자가 문서 하나로 혼자 설치·첫 실행까지 도달한다 | 외부 3~5명 실기 |
| R7 | 보안 체크리스트 5건 중 로컬 배포에 해당하는 항목이 적용됐다 | 체크리스트 서명 |
| R8 | 회귀 테스트 전량 통과(기존 환경 갭 2건 제외) | pytest |

**하지 않는 것(확정):** 예화 생성, 이미지·영상 클립, SNS 자동 게시, SaaS/멀티테넌트,
`core/retrieval.py` 변경, Apple 서명 전환(HQ 결정 전).

## 4. 순서와 임계 경로

```
주차   S1(안전장치)  S2(법적)     S3(인용)      S4(객체)      S5(패키징)
 1     S1-1~4 ████   S2-1 ██                                  S5-1~3 ███
 2                   S2-2~4 ███   [C1 회신 대기] S4-1 █        S5-4 █
 3                                S3-1~3 ████   S4-2 ████
 4                                              S4-3~4 ██     S5-5 █
 5     ── S6-1 회귀 ── S6-3 외부 실기 시작 ──────────────────
 6~7   ── S6-3 피드백 반영 ── S6-4 Release ──
```

임계 경로: **G0(D1·D3·D5·D7) → S3(C1 회신) → S4-2 → S6**. HQ 결정과 C1 회신이 1주 안에
오지 않으면 전체가 그만큼 밀린다. 그 사이 S1·S5는 진행되므로 **결정 지연이 작업 정지로
이어지지 않는다**. 총 5~7주(1인 개발, 실기 검증 포함) 추정.

**S3 없이 배포 가능한가** — 가능하나 R2가 깨진다. 인용에 제목이 없는 상태로 나가면
"출처 확인 가능"이라는 앱의 정체성 주장이 거짓이 된다. C1 회신이 2주 넘게 지연되면
**RQ-1을 "Model 무변경"으로 가정한 최소 구현(제목·저자 2키만)**을 HQ 승인 하에 선행하는
대안을 둔다. Evidence Before Promotion Rule에 따라 HQ 명시 승인 없이는 착수하지 않는다.
