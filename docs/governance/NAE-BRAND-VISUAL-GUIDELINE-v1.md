# 내서재(NAE, 內書齋) 브랜드 비주얼 가이드라인 v1

**출처:** Stitch 작업 중 Human HQ 승인 문서로 전달됨 (2026-08-19)
**관계 문서:** [DBMA-BRAND-GOV-001.md](DBMA-BRAND-GOV-001.md) (네이밍/노출 규칙),
`docs/NAE-UX-STITCH-MASTER-PROMPT-v2.md` (Stitch 프롬프트 규칙)

이 문서는 DBMA-BRAND-GOV-001의 네이밍 규칙에 더해 **시각 디자인 표준**을
정의한다. 향후 모든 '내서재(NAE)' UI 개발의 표준으로 적용된다.

---

## 1. 브랜드 정체성
- 브랜드명: 내서재 (영문: NAE / 한자: 內書齋)
- 핵심 가치: 학술적 우아함, 신뢰, 지적인 깊이, 기술과 전통의 조화
- 비전: 목회자와 신학자를 위한 전용 디지털 서방(書房)

## 2. 디자인 원칙
- Scholarly Elegance — 고전적 서재의 따뜻함 + 현대적 미니멀리즘
- Intention over Interaction — 절제되고 부드러운 인터랙션
- Paper-like Texture — 웜 톤 배경 + 종이 질감 레이어링
- No-Shadow Tonal Layering — 그림자 대신 톤 차이 + 1px 라인

## 3. 시각적 요소
- Typography: Hanken Grotesk(본문 UI) + Serif 혼용(국문/강조)
- Color: Surface `#FBF9F4`, Primary `#2C3333`, 저채도 베이지/브라운 accent
- Iconography: 2px 라인 아이콘, 유기적·고전적 메타포

## 4. 기기별 UX
- Desktop: 넓은 여백, 다중 창, 심층 연구용 메인 워크스테이션
- Mobile: 한 손 조작, 하단 내비게이션, 메모·AI 대화·빠른 훑어보기
- Tablet(iPad): Apple Pencil 주석, 듀얼 뷰 문헌 대조에 최적화

## 5. 모션 가이드
- Entrance: 순차적(Staggered) 진입
- Transition: Ease-in-out
- Ambient: 미세한 부유(Floating) 효과
