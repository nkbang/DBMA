## 0. 한 줄 판정

**"설교 도구"로서의 기능 폭은 상업 제품 하위권이나, "근거 있는 설교 준비 도구"로서의
안전성·추적성은 어느 상업 제품도 갖추지 못한 수준이다. 현재 상태는 상업 제품 대체재로는
부적절하고, 목회자 개인 서재 기반 로컬 연구 보조기로는 적절하다.** 이 포지션에서
벗어나 기능 폭으로 경쟁하는 것은 부적절하다(§4).

## 3. 축별 판정

### 3.1 우위 — 상업 제품에 없는 것 (유지·강화)

1. **근거 계층의 깊이.** TSU 단위 인용, ClaimGuard, doctrine_check, groundedness judge를
   한 파이프라인에 갖춘 제품은 없다. Preachly가 "투명 인용"을 내세우지만 설교 작성은
   하지 않고, Logos는 책 단위다. 한국 조사의 "신뢰 82 / 만족 55" 격차는 정확히 이
   지점에서 벌어진다.
2. **데이터 주권.** 목회자의 설교 원고·장서가 외부 서버로 나가지 않는다. 상업 제품
   전부 클라우드. 무료 배포의 구조적 근거이기도 하다(서버 원가 0).
3. **한국어 설교 문법.** 5개 설교 형식과 문체 파일, 한글 성경 연동 경로. 조사한 상업
   제품 어느 것도 한국어 설교 구조를 지원하지 않는다.
4. **정직한 유보.** 자료 0건이면 0건으로 끝내는 정책(예화 금지 규칙, 유보응답 PR #13).
   상업 제품은 항상 무언가를 생성한다 — SermonGPT·ChatGPT는 "신학 오류를 빈번히
   도입"한다고 경쟁 비교 자체가 적시한다.

### 3.2 열세 — 상업 제품이 당연히 갖춘 것

1. **설교가 저장되지 않는다.** 가장 큰 결함. 매트릭스 ✗ 5행(적용·강단·재활용·시리즈·
   저장)의 공통 원인이다(`DBMA_SERMON_ARTIFACT_PIPELINE_DESIGN_v1.md` §1). SermonAI는
   자동저장, Pulpit AI는 제품 전체가 "저장된 설교 1편"에서 출발한다.
2. **출력 형식.** Markdown 다운로드뿐. 슬라이드·Word·강단 모드 없음.
3. **원어 도구.** SermonAI Strong's, Logos 원어 도구 대비 청킹 수준의 인식만 있다.
4. **콘텐츠 규모.** 배포용 코퍼스 6,380 TSU / 스펄전 4종. Logos 500+권, SermonAI 58주석.
   단, 이것은 §4에서 밝히듯 **싸울 축이 아니다**.
5. **인용 메타데이터 비어 있음(B-3).** 우위 1번이 화면에서는 반쪽이다 — 출처 승인은
   되는데 "무슨 책 누구"가 안 찍힌다. C1 회신 대기 중(RQ-1/RQ-2).

### 3.3 동등

기본 RAG 설교 개요 생성·확장, 대화형 조사(chat 페이지), 교단/교리 정렬(SermonAI 인터뷰·
Aligned 설정 ≈ DBMA doctrine_filter).

## 4. 적절성 판정

| 질문 | 판정 | 근거 |
|---|---|---|
| 상업 제품 **대체재**로 지금 배포해도 되는가 | **부적절** | B-1(빈 코퍼스 생성 차단 없음)·B-3(인용 null)·설교 미저장. 목회자가 기대하는 기본기 결여 |
| **로컬 개인 서재 연구 보조기**로 적절한가 | **적절** | 우위 1~4가 이 용도에 정확히 대응. 한국 수요(조사 81%·점검 35%)와 일치 |
| 기능 폭으로 상업 제품을 따라가야 하는가 | **부적절** | 1인 개발, 로컬 LLM(8B) 제약. 예화·이미지·클립은 HQ 규칙 또는 §7 포기 항목. 열등한 모방은 영원히 뒤진다(설계 원칙 1) |
| 아키텍처가 목적에 맞는가 | **적절, 단 SaaS 불가** | 세션당 코퍼스 전량 메모리 적재(`retrieval.py:1414`)는 개인용엔 맞고 멀티테넌트엔 치명적(SaaS 제안서 §2-1). 현재 방향(무료 로컬 배포)과 정합 |
| 안전 정책이 시장 대비 과도한가 | **적절(과도하지 않음)** | Logos Sermon Assistant조차 "AI 초안 opt-out 부재"로 목회 진정성 논란. DBMA의 예화 금지·유보응답은 차별점이지 결함이 아님 |

**종합: 적절하다 — 단, "무엇으로서"가 정해진 상태에서만.** DBMA/NAE는
"근거 없는 설교를 만들지 않는 로컬 연구 보조기"로서 상업 제품이 비운 자리를 정확히
차지한다. 그 자리를 지키려면 아래 순서가 필요하다.
