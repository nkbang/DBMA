# DBMA Documentation Overview

## 목적
이 문서는 DBMA 문서 전체의 간단한 소개와 사용 안내를 제공한다.
새로 들어온 사람이 문서 체계를 빠르게 이해할 수 있도록 돕는다.

---

## 문서 구성

- `CLAUDE.md`
  - 프로젝트 운영 규칙과 개발 원칙.
- `docs/INDEX.md`
  - 문서 전체 목차.
- `docs/README_DOCS.md`
  - 문서 폴더 사용법 안내.
- `docs/ARCHITECTURE.md`
  - 시스템 구조 설명.
- `docs/PIPELINE.md`
  - 처리 흐름 설명.
- `docs/STATE.md`
  - 현재 상태와 진행률.
- `docs/PROCESS_LOG.md`
  - 작업 기록.
- `docs/TODO.md`
  - 해야 할 일 목록.
- `docs/DBMA_MAP.md`
  - 함수와 모듈 연결도.
- `docs/PROGRESS.md`
  - 진행률 요약.
- `docs/CHANGELOG.md`
  - 변경 이력.
- `docs/ARCHIVE.md`
  - 보관 문서.
- `docs/NOTES.md`
  - 임시 메모.

---

## 사용 방법

1. 먼저 `CLAUDE.md`를 본다.
2. 구조가 궁금하면 `docs/ARCHITECTURE.md`를 본다.
3. 실제 흐름은 `docs/PIPELINE.md`를 본다.
4. 현재 상태는 `docs/STATE.md`와 `docs/PROGRESS.md`를 본다.
5. 작업 기록은 `docs/PROCESS_LOG.md`를 본다.
6. 연결 구조는 `docs/DBMA_MAP.md`를 본다.
7. 오래된 내용은 `docs/ARCHIVE.md`를 본다.
8. 임시 생각은 `docs/NOTES.md`에 적는다.

---

## 문서화 원칙

- 문서는 짧고 분명해야 한다.
- 한 문서는 한 목적을 가진다.
- 구조, 흐름, 상태, 기록을 섞지 않는다.
- 바뀐 내용은 바로 반영한다.
- `dbma.py`를 기준으로 설명한다.
