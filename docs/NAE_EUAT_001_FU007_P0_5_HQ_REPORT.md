## 1. 결론 (요약)

P0-5의 질문은 "PEB가 검색된 NAE 근거에 기반해 답하는가"였다.

1. **자료가 없는 주제에서는 근거 없이 지어내지 않는다.** 코퍼스에 없는 주제 6건(G1~G3, F1~F3)은 모두 유보했다. G1~G3은 서로 다른 두 생성 표본에서 모두 유보했다.
2. **자료가 있는 질문에서는 근거 밖 내용이 사실처럼 섞여 나온다. 24건 중 9건이 해당한다.**
   - 답변의 상당 부분이 근거 밖인 사례: 6건(D1·D2·D3·C1·C2·H3)
   - 한두 문장만 근거 밖인 사례: 3건(C3·B1·A3)
3. 근거 밖 진술에 **출처 표기가 함께 붙는 경우가 많다.** 출처가 틀린 사례도 2건(A3·D2) 있다. 출처가 붙어 있으면 근거 밖 진술이 근거 있는 것처럼 보인다.
4. 근거와 일치한 답변은 7건(A1·B2·E1·E2·E3·H1·H2)이다. 이 가운데 E3는 근거와 일치하지만 질문과 어긋난 답이다.

**한 문장 결론**: 결합안 PEB는 자료가 없을 때 유보하는 동작은 확인됐다. 하지만 자료가 부분적으로 있을 때 모델 내장 지식으로 빈칸을 채우는 누출이 대표 질의의 3분의 1(9/24)에서 관찰됐다. 따라서 **"검색 근거에만 기반해 답한다"는 주장은 현재 성립하지 않는다.**
