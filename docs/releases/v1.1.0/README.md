# DBMA v1.1.0 — Release Overview

**DBMA (David Bang Ministry Archive)** is a **Stable Research Platform** designed for Korean theological corpus analysis, retrieval, and semantic research.

---

## What Is DBMA?

DBMA is a **production-grade research engine** built through 15 development sprints (Sprint 1 → Sprint 15) that provides:

- **Retrieval-Augmented Search**: Hybrid BM25 + Vector retrieval from a curated Korean theological corpus
- **Metadata Intelligence**: Book detection, reference parsing, theme classification
- **Evaluation Framework**: Fingerprint-based validation with gold-standard benchmarking
- **Document Processing**: PDF ingestion, chunking, embedding pipeline
- **Interactive UI**: Streamlit-based research interface
