## 2. 시작 전 확인된 구조적 차이 (착수 전 필독)

### 2.1 사이드바 용도 불일치 — 가장 중요한 caveat

현재 `ui/sidebar.py`(44줄)는 **파이프라인 설정 패널**이다(RAW 폴더 경로,
출력 폴더, chunk size/overlap, OCR 여부). UX 목업의 사이드바는 **내비게이션
메뉴**(홈/자료 찾기/내 자료/연구하기/설교 준비/도움말)로, 목적이 완전히
다르다.

**결정 필요**: 아래 중 하나를 HQ가 먼저 선택해야 구현 순서가 정해진다.

- (A) 설정 패널은 별도 화면/모달로 이동시키고, 좌측 사이드바를 UX 목업처럼
  내비게이션 전용으로 교체
- (B) 기존 설정 사이드바는 유지하고, 내비게이션은 상단 탭 또는 별도 영역에
  추가
- (C) 둘을 한 사이드바 안에 섹션으로 공존시킴 (상단: nav, 하단: 설정,
  접이식)

**본 Task Order는 (A)를 기본 전제로 작성한다** — Design Brief §2.2가
내비게이션 라벨 교체를 명시적으로 요구했기 때문. (B)/(C)를 원하면 착수
전에 알려줄 것.

### 2.3 구조적 이슈 (C1 S1) — 검색 카테고리 대조

`search_results.html`의 5분류 탭("성경/책/신학자료/설교/내 자료")이
`core/retrieval.py`가 실제로 반환하는 카테고리와 일치하는지 **구현 시작
전에 먼저 확인**한다. 불일치하면 UI 탭을 실제 카테고리에 맞게 조정하고,
Stitch 목업 쪽 문서는 사후 갱신(코드가 기준, 목업은 참고용).

## 5.1 실제 구현 상태 재확인 (2026-07-31) — 이 문서의 전제 정정

착수 전 라이브 코드를 다시 확인한 결과, P0 화면 대부분이 **이미
구현되어 있음**을 확인했다. 목업 기준 전면 재구성은 불필요하고
회귀 위험이 크므로 하지 않는다.

- 홈(`dashboard.py`): 실데이터 기반으로 이미 재설계됨 (상태 배너 +
  퀵액션 3개 + 내 서재 요약). 목업과 레이아웃은 다르지만 기능적으로
  더 발전된 상태
- 검색: 별도 화면이 아니라 `research.py`(연구하기)에 "Stitch Style"로
  이미 구현됨
- 도움말(`help.py`): 이미 Stitch 토큰(`THEME`) 사용해 구현됨
- 내 자료(`library.py`): 811줄 실제 문서 관리 기능 존재

**남은 진짜 격차— Sample Library (Design Brief §2.5)**: "기본 자료
(읽기 전용) vs 내 자료" 구분과 샘플 콘텐츠 자체가 없음. 온보딩의
"샘플 자료로 시작하기" 버튼이 실제로는 아무 샘플 데이터도 넣지
않고 Library로 이동만 시킴 — 신규 사용자가 빈 화면을 보게 됨
(Design Brief §1.2 "Sample-driven Onboarding" 원칙 위반).

**임시 조치 (완료)**: 버튼 라벨을 실제 동작에 맞게 "바로 시작하기"로
수정해 거짓 약속 제거.

**보류(미착수)**: 실제 샘플 데이터 세트 구축 + 읽기 전용/복사 로직
구현 — 별도 Task Order 필요, 이번 라운드 범위 아님.
