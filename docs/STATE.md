# DBMA State

## 현재 상태
DBMA는 신학 문서 전용 RAG 시스템으로 개발 중이다.
현재 우선순위는 파싱 안정화, md 산출물 생성 정상화, 청킹 흐름 점검, 그리고 UI 탭 흐름 개선이다.

---

## 프로젝트 진행률

전체 진행률: 35%

### 세부 진행
- 구조 확인: 100%
- 문서화 기준 정리: 100%
- CLAUDE.md 정리: 100%
- TODO 정리: 100%
- 파싱 안정화: 40%
- md 산출물 생성: 30%
- 청킹 최적화: 35%
- UI 탭 안정화: 40%
- RAG 흐름 점검: 25%
- 평가 루프 정리: 20%

---

## 현재 우선순위

1. md 파일 생성이 실제로 되는지 확인한다.
2. 청킹 최적화가 실제 실행되는지 확인한다.
3. 처리 중 UI 탭 비활성화 문제를 고친다.
4. RAG 흐름을 점검한다.
5. 평가 루프를 정리한다.

---

## 현재 작업 원칙

- 한 번에 하나씩 고친다.
- 변경 후 바로 검증한다.
- 로그를 남긴다.
- 문서화는 md 파일로 한다.
- 추측보다 실행 결과를 본다.
