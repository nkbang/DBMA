## 2. 실측 1 — 현 기본 설정에서 17건 전수

`USE_INVERTED_INDEX` 기본값 `true` (2026-09-18 전환) 상태, `HybridQueryProcessor`.

```
A1 A2 A3 C1 C2 D1 D2 D3 E1 E2 E3 F2 G3 H1 H2 H3  → 후보 0건 (16건)
G2                                                → 후보 5건
```

**후보 0건 = 16/17.** 파이프라인이 Stage-2(신학 점수·구절 점수)에 도달하지 못하고
빈 리스트로 끝난다.

G2만 후보가 나온 것은 개선이 아니다 — G2는 *"「존 스미스 3세」라는 신학자가
주장했다는 교회론"*, 즉 **존재하지 않는 인물을 묻는 환각 트랩**이다. 0건이
정답이었어야 할 유일한 질의에서만 후보가 5건 나왔다.

## 4. 근본 원인

```
한국어 질의
  → Query Planner route 분류
  → Stage-1 후보 생성 = Tantivy 역색인 (어휘 일치, core/candidate_generator.py)
       영문 코퍼스와 한국어 토큰의 어휘 교집합 = 0
  → candidates = []
  → core/hybrid_candidate_pipeline.py:148 `for cand in candidates:` 가 0회 실행
  → 폴백 없음 → 결과 0건
```

`HybridRetriever`에는 **Stage-1이 비었을 때의 폴백 경로가 없다**(코드 확인:
:113~143에서 route별로 후보를 채우고, :148 루프가 그걸 그대로 소비한다).
교차언어 능력을 가진 임베딩(`bge-m3`, 다국어)은 Stage-2 이후에 있어 **도달하지
못한다.**

### 왜 09-18 이전에는 드러나지 않았나

2026-09-15 세션에서 한국어 질의 `설교자의 기도`로 영문 스펄전 코퍼스 검색이
정상 동작함을 실측한 기록이 있다(`DBMA_BASELINE_CORPUS_LOAD_REPORT_001.md` §4 —
*"한국어 질의 → 영어 코퍼스 교차 검색 동작 확인(bge-m3 다국어)"*). 그때는
역색인 경로가 기본이 아니었다.

2026-09-18에 `USE_INVERTED_INDEX` 기본값을 `true`로 전환한 것은 O(N) 콜드 스캔
지연(수 분)을 해결하기 위한 **정당한 조치**였다(STATE.md 기록, 0.95초로 개선).
그러나 그 전환이 **교차언어 검색을 함께 끊었다** — 이번 실측이 그것을 확인한다.

## 5. 단순 되돌리기는 답이 아니다

`USE_INVERTED_INDEX=false`로 돌리면 한국어 질의가 살아나지만:

1. **A1이 22.0초** — 09-18에 고친 바로 그 콜드 스캔 문제가 재발한다. 배포 차단 사유였다.
2. **변별력이 의심스럽다** — OFF에서 A1·E2·H1·D2 네 질의의 최상위 출처가 모두
   `Broadus_Lectures_on_History_of_Preaching`으로 동일하고 점수도 0.369~0.394에
   몰려 있다. 서로 무관한 네 주제가 같은 문헌을 최상위로 내놓는 것은 의미 기반
   매칭이 아니라 TF-IDF 폴백류의 약한 매칭으로 보인다. **OFF는 "0건이 아닌
   상태"일 뿐 "올바른 검색"이라는 증거가 없다.**

즉 현재 양쪽 모두 결함이다: **ON = 한국어 재현율 0%, OFF = 느리고 변별력 불명.**

## 6. 권고 — Stage-1 빈 결과 폴백

최소·원칙적 수정: **Stage-1이 0건이면 의미 검색 경로로 폴백한다.**

- 현재 0건은 막다른 길이므로 폴백은 **순손실 없는 개선**이다(0건보다 나쁠 수 없다).
- 빠른 경로(역색인)를 기본으로 유지하므로 09-18의 지연 개선이 보존된다.
- 폴백은 0건일 때만 발동하므로 절대다수 질의의 성능·결과가 불변이다.

부가 검토 사항(별건):
- **A1·A2는 영어로도 0건** — scripture reference가 포함된 질의의 `bible` route
  동작을 따로 봐야 한다. 이번 원인과 다를 수 있다.
- OFF 경로의 변별력(§5-2) 자체를 측정해야 한다. 폴백을 붙이더라도 폴백이
  내놓는 결과가 쓸 만한지는 별개 문제다.
- 근본적으로는 **한국어 자료 부재**가 남는다. 기준선이 전량 영문이므로, 폴백이
  동작해도 목회자는 영문 근거를 받는다. Fuller/Dagg/Hiscox 편입 또는 한국어
  자료 확보는 별도 HQ 결정 사항이다.
