## 작업 사항 — S6-2: P0-5 대표 질의 24건 인적 채점

### 0단계 — 착수 전 필수 확인 (1개, 사실 확인만)

`docs/NAE_GOLD_QUERY_SET_P0_5_RESULT_001.md`(사람이 읽는 채점용 문서,
mtime 2026-09-18 02:12)가 `docs/NAE_GOLD_QUERY_SET_P0_5_RAW_ANSWERS_001.json`
(원본 답변, mtime 2026-09-23 00:28 — **더 최신**)과 **내용이 다르다**는
것을 이미 확인했다(재조사 불필요). 즉 사람이 보는 채점 문서가 사이드카
백필 이후 재실행분을 반영하지 못한 구버전이다.

**0단계 작업**: `scripts/p0_5_run_all.py`를 읽고, 이 스크립트가
`RESULT_001.md`(사람이 읽는 문서)도 함께 재생성하는지 확인한다.
- 재생성한다면: 그냥 재실행해서 `RESULT_001.md`를 최신 JSON과 일치시킨다.
- 재생성하지 않는다면(단순 JSON만 갱신하는 스크립트라면): `RAW_ANSWERS_001.json`
  24건을 직접 읽어 `RESULT_001.md`와 같은 형식(질의별 원문 답변 나열)으로
  **CUE가 직접 재작성**한다 — 새로 답변을 생성하지 말고, 이미 있는 JSON의
  내용을 그대로 사람이 읽기 좋은 형식으로 옮기기만 한다.

이 0단계는 코드 실행/문서 재작성일 뿐 판단이 필요 없다 — 승인 없이
진행 가능(CLAUDE.md CUE Operating Policy, 사소한 작업).

### 1단계 — 채점 시작 안내

0단계가 끝나면 사용자에게 아래를 안내한다:

1. 채점 도구(Artifact) 링크: `docs/NAE_GOLD_QUERY_SET_P0_5_001.md` 상단
   `scoring_tool`.
2. 갱신된 `docs/NAE_GOLD_QUERY_SET_P0_5_RESULT_001.md`를 보며 8개 축
   (자료 충실성·신학적 정합성·출처 투명성·문맥 보존·목회적 유용성·
   언어 완성도·불확실성 정직성·신학적 혼합 방지)으로 24건 채점.
3. 정직 유보 답변(근거 0건 인정)은 슬라이더 무시, 수동 PASS.

**채점 실행 자체는 사용자만 할 수 있는 임계 경로다 — CUE가 대신
채점하지 않는다.** CUE의 역할은 자료를 최신·정확하게 준비하는 것까지.
