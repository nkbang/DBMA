# 내서재(NAE) — 기능 정리서 & 제작 의뢰서

> **대상**: Stitch HTML 목업 및 브라우저 검증
> **디자인 시스템**: `DESIGN.md` (Theological Archive System)
> **브랜드**: 내서재 / NAE (대문자)
> **버전**: v1.3.0

---

## 1. 전체 아키텍처 (페이지 흐름)

```
랜딩 → 온보딩 → 홈 대시보드
    ├─ 내 자료 (문서 라이브러리)
    ├─ 검색·연구 (검색 + 결과 카드 + AI 답변 병렬)
    │   └─ 자료 읽기 (본문 전체 뷰어)
    ├─ AI에게 질문 (RAG 채팅 — 대화 연속성)
    ├─ 설교 연구 (검색 자료 모아보기 → 개요 초안)
    │   └─ 설교 준비 (본문/주제 → 검색 → 개요 → 확장 → 초안)
    ├─ 설교 리뷰 (모음 파일 분리 → 검수 → 등록)
    └─ 도움말
```

| **설교 연구에 추가** | 각 카드에 "설교 연구에 추가" 버튼 → 설교 연구 허브로 이동 |
