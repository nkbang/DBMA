## 3. 구현 작업 기준

각 항목은 기존 HTML 목업과 GAP 문서(§5, §3-4~3-7)의 요구사항을 기준으로
구현한다. Figma 임포트나 별도 디자인 파일 제작은 사용하지 않는다.

```text
[브랜드 규칙] "내서재"/"NAE" 브랜드만 사용, "DBMA" 등 내부 식별자 노출 금지,
RAG/Retrieval/Embedding/TSU/Chunk/Vector 등 기술 용어 노출 금지, 모든 텍스트는
한국어·목회자 언어로. 기존 프로젝트의 사이드바/헤더/푸터 컴포넌트를 그대로
재사용할 것. 기존 화면들과 같은 디자인 시스템을 따를 것.

TASK: 기존 사이드바에 "설교 모음 정리" 항목을 추가하고, 다음 사양으로 새
화면(sermon_review)을 만들어줘.

- 상단: 합본 설교 파일 업로드 영역
- 업로드 후: 자동으로 개별 설교 단위로 분리된 목록, 페이지네이터
  ("1 / 12편" 형식)
- 각 항목: 제목/날짜/성구(자동 추출, 실패 시 "직접 입력" 안내 문구와
  수동 입력 폼)
- 각 항목에 저장 액션 버튼
- 빈 화면 없이 샘플 데이터(설교 3~4편)로 채워서 보여줄 것
```

다음 구현 항목은 GAP 문서 §3-4~§3-7과 기존 HTML 목업을 기준으로 작업한다.
